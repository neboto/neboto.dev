Read-only is the point

nebaz issues only GETs against Azure Resource Manager and Microsoft Graph, and a test fails the build if that ever changes. Keys, connection strings, app settings and secret values are never fetched: Key Vault shows secret names, never values. When you do want to change something, C copies the az command instead.
