One resource, every angle

A security group's inbound rules, what uses it, and a link to every group it references — one pane, no tab-hopping. The SSH rule someone forgot stands out.

Read-only is the point

Every assumed cross-account session is pinned to the AWS-managed ReadOnlyAccess session policy, and the full IAM footprint is documented action by action in PERMISSIONS.md. Security teams can approve it because it cannot mutate. When you do want to change something, C copies the ready-to-run AWS CLI command for the selected resource, region and ids filled in.

On Azure: nebaz

nebaz is neboto's Azure sibling: the same keyboard-driven, read-only terminal UI, built on the same core and signed in through the Azure CLI. It covers 20 services, including VMs, Storage, Networking, Key Vault, AKS, App Service, SQL, Cosmos DB and Container Apps, with the network access lens, the change timeline and @audit. It is early and experimental. Try it with nebaz --demo, no Azure account needed.
